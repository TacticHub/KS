# Character art assets: Omen & the Feline Flame

Fan-created mascots for Kingdom 1625's Kingshot strategy guide. Omen is a knowledgeable VIP alliance member, not a kingdom commander. The Feline Flame is his magical companion.

These are individual WebP files, suitable for placing independently in guide sections. Filenames identify poses; the name Omen is not printed on the gesture artwork. Some assets have colored backgrounds and are **not** transparent cutouts.
