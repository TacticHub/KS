📖 Planner's Guide - Step by Step
How to set up a legion, build the roster, and share it in game and on Discord ▼
Set up
1
Choose a legion and time
Open the Legion 1 or Legion 2 tab. Set the start time in UTC (your local time shows beside it) and add any rally notes.
2
Choose how to assign
In Assign By, pick:
  • Groups - players go to Group 1, 2, or 3
  • Buildings - each player also gets a specific building
  • Both - buildings, posted under each group
3
Inside / Outside Optional
Turn on Inside / Outside Strategy if you're using it. Players get tagged I (stay in the safe zone, garrison everything) or O (roam out to capture, back before 10:00).
Build the roster
4
Add players
Tap ＋ Add Player on a group card, or Upload Excel / CSV to fill both legions at once. Imported DPS and Farm/Support players are sorted automatically; imported tanks and healers all land in Group 1, so check that card after importing.
5
Assign roles
For each player set the Role: Lead (or Tank 1-3), Healer, DPS, or Farm/Support. Then set Building and I / O if those are turned on. The map sidebar lists each building's points and perks.
Share
6
In-game chat
Tap 💬 Copy on a group card to copy that group, or 💬 Copy In-Game Chat for the whole legion. Paste each block as its own message in your legion chat. Leads go on the Lead: line; everyone else is listed with (I) or (O).
7
Discord
Tap 📋 Generate Discord Output, then Copy to Clipboard and paste into your Discord channel. For a picture, use 🖼 Visual Export and screenshot it or print to PDF.
8
Save the plan
Tap 💾 Save Plan to store it in the cloud archive. Open 📚 Archive to load, export, or delete past plans. Saved plans are shared with everyone who uses this planner.
⚠ Save before you leave. The planner doesn't auto-save. Refreshing or closing the page clears anything you haven't saved to the archive.
